# 📂 Practice Directory Overview

This directory contains standalone, isolated practice modules:

```
practice/
├── props-data-flow/          # Props passing, child components, and button click callback flow (Port 5174)
├── state-lifting/            # Sharing state between siblings via common parent (Port 5175)
└── day-1-to-5-curriculum/    # Daily practice curriculum (Day 1 to Day 5 full exercises & solutions)
```

---

## 🚀 Running Any Module:

### 1. Props Data Flow
```bash
cd props-data-flow
npm run dev
# Open http://localhost:5174/
```

### 2. State Lifting
```bash
cd state-lifting
npm run dev
# Open http://localhost:5175/
```

### 3. Day 1 to 5 Curriculum
```bash
cd day-1-to-5-curriculum
npm run dev
# Open http://localhost:5173/
```
