# 📂 Practice Directory Overview

This directory contains standalone, isolated practice modules:

```
practice/
├── props-data-flow/          # Props passing, child components, and button click callback flow (Port 5174)
├── state-lifting/            # Sharing state between siblings via common parent (Port 5175)
├── usestate-hook/            # Deep-dive into useState with numbers, booleans, and strings (Port 5176)
├── conditional-rendering/    # Login/Logout conditional rendering with ternary & && (Port 5177)
└── day-1-to-5-curriculum/    # Daily practice curriculum (Day 1 to Day 5 full exercises & solutions)
```

---

## 🚀 Running Any Module:

### 1. Props Data Flow
```bash
cd props-data-flow
npm run dev
# Open http://localhost:5174/
```

### 2. State Lifting
```bash
cd state-lifting
npm run dev
# Open http://localhost:5175/
```

### 3. useState Hook
```bash
cd usestate-hook
npm run dev
# Open http://localhost:5176/
```

### 4. Conditional Rendering
```bash
cd conditional-rendering
npm run dev
# Open http://localhost:5177/
```

### 5. Day 1 to 5 Curriculum
```bash
cd day-1-to-5-curriculum
npm run dev
# Open http://localhost:5173/
```
